# GONGGAMLINE AI v3.1.2

## 추가 기능

- 쿠팡 카테고리 메타정보를 필수/선택 속성 카드로 표시
- 선택 가능한 속성값을 태그 형태로 표시
- 필수 구매옵션을 첫 번째 상품 옵션의 `attributes`에 자동 반영
- 원본 API JSON 접기/펼치기
- 카테고리 코드 입력 시 숫자만 허용

## 적용 파일

- `app/coupang/register/page.tsx` 교체
- `app/globals.css` 교체 또는 v3.1.2 스타일 블록 추가
- `README-v3.1.2.md` 추가

## 주의

자동 반영 후 값이 비어 있는 필수 속성은 실제 상품에 맞게 입력해야 합니다. 실제 등록 전 출고지, 반품지, 이미지, 고시정보, 인증정보를 반드시 검토하세요.
