- Added a binding repository standard for automatic task-branch selection and
  recovery from Git evidence instead of device-local Codex conversations.

  auto-merge behavior while retaining manual approval for high-risk,
  Production, database, authorization, secret, commerce-write, paid, and
  destructive actions.

  sounds.

  state changed.
