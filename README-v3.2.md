# 공감라인 AI v3.2 패치

## 추가 기능
- 상품 후보 카드에 `쿠팡 등록` 버튼 추가
- 선택한 상품의 상품명, 상품번호, 키워드, 판매가, 대표 이미지, 원본 URL을 등록 워크벤치로 전달
- `/coupang/register`에서 쿠팡 상품 등록 JSON 초안 자동 생성
- 자동 생성된 값의 출처와 예정 판매가 표시

## 복사할 파일
- `app/page.tsx`
- `app/coupang/register/page.tsx`
- `app/globals.css`

## 주의
이 버전은 카테고리 코드를 자동 결정하지 않습니다. 상품 후보 데이터로 JSON 초안을 만든 뒤, WING에서 확인한 노출 카테고리 코드로 메타정보를 조회해야 합니다. 출고지, 반품지, 고시정보, 인증정보는 실제 운영값으로 확인해야 합니다.
