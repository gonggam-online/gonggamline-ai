# Item Selection Discovery Profitability v1

상품선정 탐색 단계에서 공개 공급처 후보를 서로 비교할 수 있도록, 확정 판매가가 없어도 손익분기·조건부·추천 판매가 하한을 계산한다. 이 결과는 구매·상품등록·가격확정 권한이 아니라 후보 발굴용 추정치다.

## 입력과 계산

- 공급가: 공급처 공개값. 없으면 계산하지 않는다.
- 공급처 배송비: 공개값을 최소주문수량으로 안분한다. 없으면 주문당 기준 3,000원, 스트레스 5,000원을 적용한다.
- 최소주문수량: 공개값이 없을 때 1개를 가정하고 미확정 사실로 표시한다.
- 검수·입고: 개당 기준 250원, 스트레스 400원.
- 3PL: 기존 수익성 정책 v4의 개당 기준 3,000원, 스트레스 3,500원.
- 기타 변동비: 기준 0원, 스트레스 200원.
- 변동률: 쿠팡 수수료 10.9%, 광고 12.5%/18%, 반품손실 4%/6%.

판매가 하한은 100원 단위로 올림한다. 조건부 하한은 기존 조건부 기여이익·마진 및 스트레스 손익분기를 모두 만족하는 최솟값이고, 추천 하한은 추천 기여이익·마진 및 스트레스 마진을 모두 만족하는 최솟값이다.

## 안전 경계

- 실제 규격·중량은 현재 승인된 공급처 계약에 없으므로 생성하거나 추정하지 않고 `productDimensionsAndWeight` 미확정으로 유지한다.
- 카테고리 수수료, 실제 3PL 견적, 실제 광고·반품률은 미확정으로 표시한다.
- 후보군 점수는 추천 판매가 하한이 낮을수록 높다. 확정 이익이나 판매 승인이 아니다.
- 실제 판매가를 입력한 경우에만 기존 수익성 계산기의 기여이익 시나리오가 생성된다.
- 모든 추정은 스냅샷에 버전·가정·미확정 사실과 함께 영속화한다.
