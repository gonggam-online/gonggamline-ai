# Item Selection Competitive Benchmark v1

## 목적

아이템선정 엔진이 실제 시장에서 경쟁력이 있는지 추측하지 않고, 동일한 후보 집합과 관측기간을 사용해 재현 가능한 방식으로 측정한다. 이 문서는 운영 판정이나 추천 순위를 변경하지 않는 읽기 전용 평가 계약이다.

## 측정 지표

- `precisionAtK`: 상위 K개 중 실제 유효 후보 비율
- `recallAtK`: 전체 유효 후보 중 상위 K개가 포착한 비율
- `ndcgAtK`: 유효성 등급(0~3)을 반영한 순위 품질
- `meanAbsoluteMarginError`: 별도로 제공된 예측 기여마진율과 관측 기여마진율의 평균 절대 오차. 일반 총점은 마진 예측값으로 취급하지 않는다.
- `coverage`: 평가 후보 중 엔진 결과가 존재하는 비율

구현은 `shared/domain/item-selection-benchmark.ts`의 순수 함수에 있다. 라벨은 승인된 immutable 평가 데이터셋에서만 공급해야 하며, 라벨이 없는 결과는 시장 경쟁력 증거로 취급하지 않는다.

## 판정 조건

`eligibleForDecision`은 최소 10개(또는 `topK*2`) 이상의 라벨 후보와 유효한 Precision/NDCG가 있을 때만 true다. 이 조건은 통계적 유의성을 보장하지 않으며, 최소 평가 표본과 지표 계산이 가능하다는 뜻이다. 실제 도입 판단에는 기간 분리 검증, 기준선 모델 비교, 실판매·반품·정산 결과가 추가로 필요하다.

## 비교 기준선

동일 후보 집합에 대해 현재 엔진, 고정 프롬프트 LLM 기준선, 단순 가격/마진 기준선을 각각 실행한다. 후보 생성·라벨링·정책 버전·관측기간이 다르면 비교 결과를 폐기한다.

## 안전 경계

이 모듈은 DB/외부 API/커머스/Production 쓰기를 수행하지 않는다. benchmark 결과는 운영 verdict, 자동 추천 순위, 구매·입고·상품등록을 변경하지 않으며 관리자 검토 자료로만 사용한다.
